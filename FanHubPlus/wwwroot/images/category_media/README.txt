FAN HUB PLUS - MEDIA FOLDER GUIDE
=================================
Is "media" folder ko project ke  FanHubPlus/wwwroot/  ke andar copy karein.
Final path:  wwwroot/media/gaming/videos/...

FOLDERS (har category ke andar same 6 folders):
  characters   -> character profile ki pictures
  images       -> gallery / general pictures
  videos       -> mp4 videos, trailers
  audio        -> mp3 soundtracks, podcasts
  merchandise  -> merchandise showcase ki pictures
  articles     -> article ki cover/embedded pictures
  general/     -> events, upcoming-releases, site (logo/banner), avatars

FILE NAMING RULE (sab lowercase, space ki jagah dash, koi urdu/special character nahi):
  <category>-<cheez>-<naam>.<ext>

Examples:
  gaming/characters/gaming-character-kratos.jpg
  gaming/videos/gaming-trailer-god-of-war-ragnarok.mp4
  gaming/audio/gaming-soundtrack-zelda-main-theme.mp3
  anime/characters/anime-character-naruto-uzumaki.jpg
  k-pop/images/k-pop-gallery-bts-concert-01.jpg
  gaming/merchandise/gaming-merch-ps5-controller.jpg

FORMATS (browser mein chalne ke liye):
  Images: .jpg .png .webp      Video: .mp4 (H.264)      Audio: .mp3

DATABASE / ADMIN PANEL MEIN PATH is tarah likhein:
  /media/gaming/videos/gaming-trailer-god-of-war-ragnarok.mp4
(/media se shuru, wwwroot likhne ki zaroorat nahi)
